# UFO sightings explorer

A browser-based table of a static sightings dataset with filters for date, city, state, country, and shape. Filters use exact values, ignore case, and apply when an input changes.

[Open the page](index.html) · [Filtering code](app.js) · [Data](data.js)

Open `index.html` in a browser with internet access for the Bootstrap and D3 CDN assets.
